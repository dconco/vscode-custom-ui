# VS Code Custom UI Setup

This repository contains `spyrochat.css`, a custom stylesheet for Visual Studio Code UI customization.

## Setup

1. Copy `spyrochat.css` to:
   - `C:/Users/PC/.vscode/spyrochat.css`
2. Replace your `.vscode/settings.json` with your VS Code configuration (open settings JSON with `Ctrl + ,`).
3. Install the **Enable Custom CSS and JS** extension.
4. Press `F1` or `Ctrl + Shift + P`, search for **Enable Custom CSS and JS**, and run it.
5. Restart VS Code when prompted.
6. If VS Code shows a corruption warning, click **Don't Show Again**.
7. Download **Google Sans Code** from:
   - https://fonts.google.com/specimen/Google+Sans+Code
8. Extract and install either:
   - `static/GoogleSansCode-Medium`
   - or the variable font
9. Reload VS Code after applying settings so the design loads correctly.
10. Install these extensions:
    - **One Dark Italic Theme**
    - **Material Icons**
